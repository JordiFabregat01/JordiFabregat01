## Crookpool · Unreal Engine 5 · private beta

[![Crookpool: four animal crooks in striped shirts and silly hats in front of a neon tower](https://jordifabregat01.github.io/media/og-crookpool.jpg)](https://jordifabregat01.github.io/crookpool.html)

Four animal crooks, one van, eight minutes. A 2–4 player online heist game: carry heavy physics loot to the van before the clock runs out, and shove your friends so they drop theirs. Listen server over Steam, four maps and a hideout.

I built the first prototype in Blueprints in three days. From the third week my friends play-tested it with me over Steam, and every session turned into a fix list for the next build: 54 iterations and 15 numbered builds so far.

**[Read the case study and watch the reel →](https://jordifabregat01.github.io/crookpool.html)** The code is private; a build is available on request.
